密钥不要写进项目目录

项目里的 .claude/settings.json 通常会提交到 Git 仓库。密钥只写在用户目录下的 ~/.claude/settings.json。

各配置项的含义

配置项说明
ANTHROPIC_BASE_URL网关地址，不带 /v1
ANTHROPIC_AUTH_TOKEN你的密钥，以 Authorization: Bearer 方式发送
CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC关闭遥测、错误上报等非必要请求。同时会关闭自动更新，需要时手动运行 claude update

请用 ANTHROPIC_AUTH_TOKEN，不要用 ANTHROPIC_API_KEY。后者在交互模式下需要手动确认一次，拒绝过一次就会被静默忽略。
