ChatGPT Desktop

在 ChatGPT 桌面客户端里的 Codex 中使用 Maru Code

使用哪个分组的密钥？

使用 OpenAI 分组 的密钥。

2026 年 7 月起，Codex 桌面版已经并入 ChatGPT 桌面客户端（macOS / Windows）。客户端中的 Codex 可以接入网关，它和 Codex CLI 共用同一个配置文件。

只有 Codex 能接入网关

ChatGPT 桌面客户端的聊天功能绑定 ChatGPT 官方账号和订阅，不支持自定义 API。想用图形界面和 GPT 模型聊天，请使用 Kelivo、RikkaHub 或 Open Minis。

配置步骤

安装 ChatGPT 桌面客户端

从 chatgpt.com/download 下载并安装。

修改 Codex 配置文件

系统路径
Windows%USERPROFILE%\.codex\config.toml
macOS~/.codex/config.toml

目录或文件不存在就新建。Windows 可以按 Win + R，输入 %USERPROFILE%\.codex 打开目录。把下面三行加到文件最开头：

已经按 Codex 教程配置过 CLI 的，可以跳过这一步。

完全退出并重新打开客户端

配置文件只在启动时读取。关闭窗口不等于退出，请从托盘 / 程序坞右键彻底退出后再打开。

用 API Key 登录 Codex

进入 Codex，在登录界面选择 Sign in another way（其他登录方式），选择用 API Key 登录，粘贴你的 sk- 密钥后点击 Continue。

注意事项

  • 用 API Key 登录时，部分依赖 ChatGPT 账号的 Codex 功能可能不可用。
  • 想换模型，修改 config.toml 中的 model 后重启客户端，模型名以模型广场中 OpenAI 分组的列表为准。
  • 不要用「方式二：自定义服务商」中的环境变量方式配置桌面客户端：从桌面图标启动的程序可能读不到终端里设置的环境变量。
  • 更多配置说明见 Codex。
