快速开始

三样东西 + 三个步骤，把任意 AI 客户端接入 Maru Code

本文档介绍如何把各家 AI 客户端 / Agent 接入基于 Sub2API 搭建的 API 网关 Maru Code（api.muteki.site）。

你需要准备的三样东西

不管用哪个客户端，需要填写的核心信息都一样：

信息填什么从哪里来
Base URLClaude 类客户端：https://api.muteki.site
OpenAI 类客户端：https://api.muteki.site/v1		见 接口地址与协议
API Keysk- 开头的密钥控制台 → API 密钥 页面创建，见 创建 API Key
模型名例如 gpt-5.6、claude-sonnet-5-5控制台 → 模型广场，名称要完整复制

Base URL 最容易填错

Claude 类客户端（Claude Code 等）会自己在地址后面拼上 /v1/messages，所以不要带 /v1；OpenAI 类客户端（Codex、大多数聊天 App）一般要求填到 /v1。填错会出现 404。

接入步骤

注册账号

打开 api.muteki.site 注册并登录。

创建 API Key

进入 API 密钥 页面新建密钥，按你要用的模型选择分组：用 GPT 系列选 OpenAI 分组，用 Claude 系列选 Anthropic 分组。详见 创建 API Key。

按客户端教程填写配置

在下面选择你的客户端，照着教程填入 Base URL、API Key 和模型名，然后发一句「你好」测试。
