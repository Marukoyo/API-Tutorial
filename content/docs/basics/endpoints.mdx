## Base URL 速查

网关同时兼容 Anthropic 和 OpenAI 两套协议。**Base URL 填什么取决于客户端用哪套协议**，而不是用哪家的模型：

| 客户端协议 | Base URL | 典型客户端 |
| --- | --- | --- |
| Anthropic Messages | `https://api.muteki.site` | Claude Code、Claude 兼容客户端 |
| OpenAI Responses | `https://api.muteki.site/v1` | Codex |
| OpenAI Chat Completions | `https://api.muteki.site/v1` | Kelivo、RikkaHub 等绝大多数聊天 App |

<Callout type="warn" title="为什么 Claude 类不带 /v1？">
Anthropic 协议的客户端会自动在 Base URL 后面拼上 `/v1/messages`。如果你填了 `https://api.muteki.site/v1`，实际请求就变成 `/v1/v1/messages`，结果是 404。
</Callout>

<Callout type="info">
有些客户端会自动在地址后面补 `/v1`，有些不会。具体以各客户端教程为准；不确定时，填完后用客户端的「检测 / 获取模型」按钮试一下。
</Callout>

## 接口列表

| 接口 | 协议 | 说明 |
| --- | --- | --- |
| `POST /v1/messages` | Anthropic Messages | Claude Code 等使用 |
| `POST /v1/chat/completions` | OpenAI Chat Completions | 大多数聊天客户端使用 |
| `POST /v1/responses` | OpenAI Responses | Codex 使用，支持 WebSocket |
| `GET /v1/models` | — | 当前密钥可用的模型列表 |
| `GET /v1/usage` | — | 查询余额与用量 |

### 跨协议调用

网关会在协议之间自动转换，但有前提：

- **Anthropic 分组**：除了原生的 `/v1/messages`，也可以通过 `/v1/chat/completions` 和 `/v1/responses` 调用 Claude 模型，所以 Claude 模型也能在 Codex 和聊天 App 里使用。如果分组被设置为「仅限 Claude Code」，则只能通过 Claude Code 调用。
- **OpenAI 分组**：原生支持 `/v1/responses` 和 `/v1/chat/completions`。能否通过 `/v1/messages` 在 Claude Code 里使用 GPT 模型，取决于站点是否为该分组开启了 Messages 转发。判断方法：控制台 **使用密钥** 弹窗里出现了 Claude Code 选项卡，就说明已开启。

## 认证方式

以下三种请求头任选其一，客户端一般会自动处理：

```http
Authorization: Bearer sk-你的密钥
x-api-key: sk-你的密钥
x-goog-api-key: sk-你的密钥
```

<Callout type="error">
不支持把密钥放在 URL 参数里（`?key=sk-...`），会返回 400 `api_key_in_query_deprecated`。
</Callout>

## 备用节点

除主站 `https://api.muteki.site` 外，还有以下接入节点，地址规则与主站完全相同（把域名换掉即可）：

| 节点 | 地址 |
| --- | --- |
| 美国 | `https://api-us.muteki.site` |
| 美国 2 | `https://api-us2.muteki.site` |
| 香港 | `https://api-hk.muteki.site` |
| 日本 | `https://api-jp.muteki.site` |

节点当前是否可用、是否支持 WebSocket 等情况，以控制台 **API 密钥** 页面的说明为准。

## 测试连通性

查询模型列表不消耗额度，适合用来检查密钥和网络是否正常：

<Tabs groupId="shell" items={['macOS / Linux', 'Windows PowerShell']} persist>
<Tab>
```bash
curl https://api.muteki.site/v1/models -H "Authorization: Bearer sk-你的密钥"
```
</Tab>
<Tab>
```powershell
curl.exe https://api.muteki.site/v1/models -H "Authorization: Bearer sk-你的密钥"
```
</Tab>
</Tabs>

返回 `{"object":"list","data":[...]}` 就说明密钥可用，`data` 里就是这个密钥能用的模型名。返回错误请对照 [常见问题](/docs/faq)。
